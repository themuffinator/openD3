OPEND3 RELEASE PACKAGE

openD3 is an open-source engine and game-code replacement for Doom 3, built from id Software's GPL source on the openQ4 engine.

This package holds the openD3 binaries and the staged baseod3/ runtime payload with the Doom 3 and Resurrection of Evil game modules. Doom 3's game data is not included: you need your own copy of Doom 3 (2004).

EARLY DEVELOPMENT

So far the main menu, the first campaign map and a dedicated-server start have been run, on Windows x64 only. Playing past the first cinematic, loading saves, level changes, joining a multiplayer server and Resurrection of Evil maps have not been tried. Release status has the details.

Requirements

Game data
Doom 3 (2004) from Steam or GOG, with its retail base/ packs at version 1.3.1. Doom 3: BFG Edition's data is a different format and is not supported.
Processor
64-bit x64.
Graphics
An OpenGL driver with ARB vertex and fragment program support, or a Vulkan 1.3 driver for the Vulkan renderer.
Storage
About 1.5 GB for Doom 3's base/ files, plus this package.
Platform
Windows x64 is the only platform openD3 has been built and run on.

No memory or performance minimums have been measured yet.

Getting Started

  1. Install Doom 3 from Steam or GOG and leave its retail base/ folder intact.
  2. Extract openD3 to a folder of its own. Never copy retail .pk4 files into baseod3/; that folder is for openD3's own files.
  3. Run openD3-client_x64.exe. openD3 finds a Steam or GOG install of Doom 3 on its own and checks its packs.
  4. If it cannot find the game, launch with +set fs_basepath "path\to\Doom 3", pointing at the folder that contains base/.
  5. To try Resurrection of Evil, launch with +set fs_game d3xp. Its game module loads, but no expansion map has been run yet.
  6. Open docs/index.html for the full offline documentation, starting with Getting Started.

Platform Notes

  • All testing so far has been on Windows x64, against the Steam release of Doom 3.
  • The openQ4 engine underneath also supports Linux, Steam Deck, macOS and Android, but openD3 has not been built or run on any of them. Treat a package for another platform as untested, and please report what happens.
  • OpenGL is the default renderer. +set r_renderApi vulkan selects the native Vulkan renderer.

Package Contents

openD3-client_<arch> openD3-ded_<arch>
The game client and the dedicated server.
renderer-gl_<arch> renderer-vk_<arch>
The OpenGL and Vulkan renderer modules, chosen with r_renderApi.
*.pdb
On Windows, diagnostic symbols that make crash dumps useful.
baseod3/pak0.pk4
openD3's own runtime content. The engine refuses to start if it is missing or modified.
baseod3/game_<arch> baseod3/game-d3xp_<arch>
The Doom 3 and Resurrection of Evil game modules. The retail gamex86 binaries are never loaded.
docs/
The offline documentation site: docs/index.html, with the user and developer references under docs/docs/user/ and docs/docs/dev/.
VERSION.txt
The packaged version and source commit.
LICENSE LICENSING.md licenses/
openD3's engine and game code are GPLv3. Files that keep Doom 3 headers also keep id Software's Additional Terms, and the third-party notices are in licenses/.

Crash Reports

On Windows, a crash writes opend3_crash_*.log and opend3_crash_*.dmp to a crashes/ folder beside the executable. Attach both, with a log from a run launched with +set logFile 2, when you report a problem.

Documentation

The package carries a full offline documentation site rather than a single readme. Start with docs/index.html, then move into the project overview, the build guide, the technical reference, the player guides and the developer notes.
